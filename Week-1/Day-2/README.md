# Day 2 – Digital Forensics Fundamentals

## 🔍 Topics Covered

### 1. Chain of Custody
Chain of custody refers to the process of maintaining and documenting the handling of digital evidence from the time it is collected until it is presented in court.

**Key Points:**
- Ensures integrity of evidence
- Tracks who accessed evidence
- Prevents tampering

---

### 2. Types of Digital Evidence

- **Volatile Data:** RAM, running processes (lost after shutdown)
- **Non-Volatile Data:** Hard disks, SSDs, logs
- **Network Evidence:** Packet captures, logs
- **Cloud Evidence:** Data stored in cloud services

---

### 3. File Systems

A file system is a method used by operating systems to store and organize files.

**Common File Systems:**
- NTFS (Windows)
- FAT32 / exFAT
- EXT4 (Linux)

---

### 4. Metadata

Metadata is “data about data”.

**Examples:**
- File creation date
- Last modified date
- Author information

---

### 5. Timeline Analysis

Timeline analysis helps investigators understand events in chronological order.

**Used for:**
- Tracking attacker activity
- Identifying suspicious behavior
- Reconstructing incidents

---

## 🧠 Key Learnings

- Digital forensics ensures evidence integrity
- Proper documentation is critical
- Timeline analysis is important in investigations
- Metadata provides hidden insights
